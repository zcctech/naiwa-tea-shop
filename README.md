# 奶娃奶茶铺 · 本地手作版

公开手作版已部署至 GitHub Pages。源码和全部模型资源保存在本仓库。

## 试玩

直接试玩：https://zcctech.github.io/naiwa-tea-shop/

无需登录，支持电脑和手机浏览器。

下载源码后，解压并在文件夹中运行 `python -m http.server 8000`，然后打开 http://localhost:8000 。JavaScript 模块和模型资源需通过静态服务器读取，不适合直接双击 HTML。

## 奶茶制作

1. 按顾客要求调整糖度和冰量，然后接待。
2. 查看配方，在材料盘中选择三样材料。
3. 指针进入绿色区域时点击「摇一下」，共三次。
4. 按住封口约 1.2 秒，在绿色区域松开。
5. 奶娃交付后结算，材料与操作共同影响手作评分和奖励。

想歇一会儿时，可以点击「这单交给奶娃」，继续使用自动制作。设备升级会扩大手作判定区，并缩短代做时间。

## 随机事件

每个营业日有最多两次轻松事件，随机出现在接待若干客人之后。点击事件提示可以选择回应：

- 小雨与晴天：改变窗外天气、室内光线及接下来两单的偏好或小费。
- 旅行画家与邻居故事：听故事获得小心意，或给接下来两单增加小费。
- 火车与野餐限时委托：接受后，90 秒内完成的接下来两单有额外小费；过期仍正常获得基础收入。

每日任务、配方、设备、升级、装饰与旧存档继续保留。手作选择和阶段也会保存，刷新后可继续制作。
